# Collabsta

AI research synthesis platform: upload papers, process them, query across sources, and generate citation-backed literature reviews.

This repository contains a **backend** (FastAPI) and **frontend** (placeholder). Application features are not implemented yet—only project scaffolding.

## Layout

- `backend/` — API service, domain modules, migrations
- `frontend/` — web client (to be added)

## Getting started

See `backend/README.md` for setup, Make targets, Docker, and CI/security tooling. Copy `.env.example` to `.env` at the repo root and adjust values before running services locally.
